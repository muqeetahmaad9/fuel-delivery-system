### 📖 Overview

Customers submit fuel delivery requests with an urgency level; an admin dashboard lists them live and approves or rejects each one.

### ✨ Features

- Request submission with urgency levels
- Admin dashboard for approve / reject
- Requests appear dynamically as they arrive
